# TiJS 文档

TiJS（`@site0/tijs`）是一套 **Vue 3 + TypeScript 的 Web UI 组件库与工具核心库**
- `core` 提供与 UI 无关的通用工具
- `lib` 提供统一注册、可配置渲染的组件及可复用特性钩子。

本站点由 `www-gen-site` 从 `docs/` 目录自动生成，正式内容是 **reference** 参考手册：

- **入门与概念** —— 从安装引导开始，理解组件模型、共享 Props、事件、国际化、样式与字典；
- **工具、组件与特性** —— 按命名空间、组件或 composable 查阅 API、示例和使用边界；
- **开发规范** —— 面向仓库贡献者，说明源码布局、新增组件、测试、构建发布与文档同步。

仓库中的 `docs/skill/` 保存面向 AI Agent 的写作流程，`docs/note/` 用于非正式过程笔记；两者均不发布到本站点。AI Agent 建议从仓库根目录的 `AGENTS.md` 开始阅读。

# `G2D` 二维几何

## 职责

`G2D` 是 `src/core/g2d/ti-g2d.ts` 导出的轻量二维几何坐标计算命名空间。目前只做一件事：
计算平面上两个点之间的欧几里得距离。它无 DOM、无依赖、纯数学函数，组件内部做拖拽命中、
两点度量等几何判断时可以直接 `import { G2D } from "@site0/tijs"` 使用。

## 导出清单

### 坐标度量

- **`getDistance(p1, p2 = { x: 0, y: 0 })`** —— 平面两点欧几里得距离
  `√((x2-x1)² + (y2-y1)²)`；省略 `p2` 时默认以原点 `(0,0)` 为另一端点。
  入参为 `Point2D = { x: number; y: number }`。

## 典型用法

```ts
import { G2D } from "@site0/tijs";

// 两点距离
G2D.getDistance({ x: 3, y: 4 }, { x: 0, y: 0 })  // 5

// 省略第二点 = 到原点距离
G2D.getDistance({ x: 3, y: 4 })                  // 5
```

## 注意事项

- **`p2` 缺省为原点**：只传一个点时算的是它到 `(0,0)` 的距离，不是到自身（自身距离恒为 0）。
- **入参不做校验**：`x/y` 为 `undefined` 或缺字段时，相减结果为 `NaN`，距离也会是 `NaN`，
  函数本身不抛错、不补默认值。
- **当前无单元测试覆盖**：`src/test/core/` 下没有 g2d 相关用例；行为直接核对
  `g2d-coord.ts` 源码得出。

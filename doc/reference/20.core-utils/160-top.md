# `_top` 顶级工具

## 职责

`src/core/_top/` 是 TiJS 最底层的一组"万物皆可用"工具：消息总线、全局环境变量、图标解析、
随机数、矩形几何、汇率与金额、颜色、范围类型。与 `Str`/`Alg`/`Num` 这些 `export * as Xxx` 的
命名空间不同，**`_top` 是平铺导出**——`ti-exports.ts` 写的是 `export * from "./_top"`，
所以这些 API 直接从 `@site0/tijs` 顶层取，不需要再挂一层对象：

```ts
import {
  createBus, version, getEnv, getRandomStr,     // 平铺函数/常量
  NumRange, StrRange, MsRange, TiColor,         // 平铺类
  Bank, Icons, Rects,                          // 少数以命名空间形式导出
} from "@site0/tijs";
```

`_top/ti-com.ts` 里的 `TiComImpl` 是组件注册表条目实现类，其机制（`TiComInfo`/race/install/
exampleProps）已由 [组件模型](../10.concepts/01-component-model.md) 讲透，本篇只列一句话职责。

## 导出清单

### 消息总线（平铺：`createBus` / `TiBusImpl`）

- **`createBus<T>(name?)`** —— 创建 `TiBus` 实例；每个实例带唯一 key 并登记进全局环境 `ALL_BUS`。
- **`TiBusImpl<T>`** —— 总线类，API：
  - **`emit(name, payload?)`** —— 发送原始消息；**`send(msg)`** —— 转发完整 `BusMsg`。
  - **`on(name, handler, deposer?)`** —— 按名字分发监听类型：`"*"` 任意监听；`^` 开头或含
    `?*+{}` 的为条件（模式匹配）监听；其余为精确监听。对应 `onAny/onMatch/onName`。
  - **`off(handler, name?)`** / `offAny/onMatch?（实为 offMatch）/offName/offAll` —— 注销；
    不传 `name` 时 `offAll` 全类型注销该 handler。
  - **`depose()`** —— 把自己从 `ALL_BUS` 摘除。
  - 消息在总线间转发时走 `busPath` 防递归：自己发出的消息不再二次处理。

### 环境变量（平铺：`version / ENV_KEYS / getEnv / setEnv / assignEnv / getAllEnv / getTimeZoneOffset`）

- **`version`** —— 取自 `package.json` 的库版本号常量。
- **`ENV_KEYS`** —— 约定的环境键名常量：`TI_DFT_DATETIME_FORMAT / TI_DFT_DATE_FORMAT /
  TIMEZONE / TIMEZONE_OFFSET`。
- **`getEnv(key, dft?)` / `setEnv(key, val)` / `assignEnv(input)` / `getAllEnv()`** ——
  读写全局 `_ENV`（lodash `get/set/assign`，支持点路径）；初始含 `dev:false`、`session:{}`、
  `ALL_BUS:Map`、`log.ROOT:0` 等。
- **`getTimeZoneOffset(tz = "Z")`** —— `"Z"` 返 0，数字原样返回，其他字符串抛错。

### 图标（命名空间 `Icons`）

- **`getIcon(input, dft?)`** —— 按 `icon → type/tp → mime → mime 主组 → race → name → dft`
  顺序解析图标；内置扩展名（`pdf/xls/png…`）、MIME、语义名（`add/edit/done/warn…`）映射表。
- **`parseIcon(val, dft?)`** —— 把字符串解析成 `IconObj`：emoji 区间判 `emoji`，
  `.png/.gif/.jpg/.jpeg/.webp/.svg` 判 `image`，`fas-xxx` 类 font-awsome 串拼 `fa-` 类名，
  其余按 image src 处理。
- **`toIconObj(val)`** —— 规范化为 `IconObj`；**`fontIconHtml(val, dft?)` /
  `fontIconHtmlWithStyle(val, style?)`** —— 输出图标 HTML 串（emoji 用 `<span>`，字体图标用 `<i>`）。
- **`isEmoji(str)`** —— 是否落在 emoji 区块。
- **`put({ types, mimes, races, names, dft })`** —— 扩充内置映射表。
- **`getDefaultIcon()` / `getDefaultIconObj()`** —— 取默认图标（`zmdi-cake`）。

### 随机数（平铺：`getRandomStr / getRandomS36 / getRandomObj / getRandomList`）

- **`getRandomStr(n = 4)`** —— 62 字符集（数字+大小写字母）随机串。
- **`getRandomS36(n = 4)`** —— 36 字符集（数字+小写字母）随机串。
- **`getRandomObj<T>(dict)`** —— 数组里随机取一项。
- **`getRandomList<T>(input = [], n = input.length)`** —— Fisher-Yates 原地洗牌后返回原数组。

### 矩形几何（命名空间 `Rects`）

- **`createBy($el)`** —— 工厂：从 `Element`（`getBoundingClientRect`）、`Document`/`Window`
  （视口 client 宽高）、`Rect`（克隆）或 `RectInfo` 对象创建 `Rect`。
- **`union(...rects)` / `overlap(...rects)`** —— 多个矩形的并集/交集。
- **`isRect(input)`** —— 鸭子类型判定（带 `__I_am_rect()`）。
- **`explainToArray(mode, sorted = true)`** —— 把 `"tlwh"` 这类简写串解析成属性名数组。
- **`pickKeys(rect, keys, dft = NaN)`** —— 按简写挑出矩形属性成对象。
- **`Rect` 类核心方法**：`updateBy(mode)` 按已知属性补全其余 8 个几何量；`raw(keys)`、
  `toCss(keys, viewport)`、`clone(border)`、`round(precise)`；位移类 `translate/moveTo/centreTo/relative`；
  缩放类 `zoom/zoomTo/contain|cover`；停靠类 `dockTo/dockIn/wrap/wrapCut`；判断类
  `contains/containsX/containsY/hasPoint/isOverlap/getOverlapRatio/area`。

### 汇率与金额（命名空间 `Bank`）

- **汇率表构建**：`useExchangeRateTable(bridge)`（流式 add/getTable 构建器）、
  `buildExchangeRateTable(input, bridge = "CNY")`、`joinExchangeRateTable(table, input, bridge = "CNY")`
  —— 按 `{currency, beginDate, endDate, rate, value}` 记录装配每日历史汇率，无 `endDate` 视为最新汇率。
- **换算**：`exchange(val, options)` —— 乘汇率；`evalExchangeRate(options)` —— 查直接/反向/桥接汇率；
  `exchangeWithCurrency(val, options)` —— 带货币符号的金额字符串换算；
  `getExchangeRateOfDate(rateSet, date?)` —— 取指定日期汇率（缺省取最新）。
- **货币元数据**：`getCurrencyChar / getCurrencyToken / getCurrencyText / getCurrencyIcon / getCurrencyList`
  —— 内置 CNY/USD/EUR/GBP/JPY/HKD/MOP/AUD/CAD 的符号、图标与 i18n 键。
- **金额解析与格式化**：`parseCurrency(input, { unit = 100, currency = "CNY" })` —— 数字/
  `"10USD"` 串/对象统一解析为 `{ cent, yuan, currency }`；`toBankText(val, options)` ——
  千分位分段；`autoYuanTokenText(cent, options)` 及 `toYuanText/toYuanTokenText/toYuanTokenText2/
  toZeroText/toZeroTokenText/toZeroTokenText2` —— 分→元带符号/补零/零值占位；
  `toChineseText(cent, capitalized?)` —— 中文大写金额。
- **支付方式**：`isValidPayType(payType)`、`getPayTypeText(payType, autoI18n?)`、
  `getPayTypeChooseI18nText(...)`。

### 颜色（平铺：`TiColor / isColor / isColorInfo / colorToStr`）

- **`TiColor`** —— 颜色类：构造接受 `#FFF`/`#FFFFFF`/`rgb()/rgba()`/`0xAARRGGBB`/颜色名单/
  灰度数字/`[R,G,B,A?]`/`{red,green,blue,alpha}`；`hex/rgb/rgba` 只读输出并缓存；
  `light/dark(degree)`、`between(other, pos)`、`updateByHSL/adjustByHSL`、`toHSL/fromHSL`、`toString()`。
- **`isColor(val)`** —— `TiColor` 实例判定；**`isColorInfo(input)`** —— `{red,green,blue}` 对象判定；
  **`colorToStr(color, dft?)`** —— `TiColor` 实例转 `toString()`，字符串原样返回。

### 范围类型（平铺：`AnyRange / NumRange / StrRange / MsRange`）

- **`AnyRange<T>`** —— 泛型区间基类，构造时注入 `{ anyToValue, compareValue, isMatchType }`；
  输入支持 `"(0,100]"` 串、数组、`{minValue,maxValue…}` 的 `RangeInfo`、`{$gt/$lt/$eq/$ne…}` 的
  `RangeObj`；`contains(v)` 判断落区间，`toString()` 还原区间串，`toRangeInfo()/toRangeObj()`
  双向导出。
- **`NumRange`** —— 数值区间，字符串直接 `Number()` 转换。
- **`StrRange`** —— 字符串字典序区间。
- **`MsRange extends NumRange`** —— 毫秒时间戳区间，额外 `containsDate(d)`、`toDateString(fmt)`、
  `toDateTimeString(fmt)`。

### 组件注册表条目（平铺：`TiComImpl`）

- **`TiComImpl`** —— 把 `TiComInfo` 包成注册表条目实例（图标/race/name/i18n/tags/exampleProps/
  install 等），提供 `getProps(name)/checkProps(name)/toString()`。组件注册、race、`liveStyle`
  等机制见 [组件模型](../10.concepts/01-component-model.md)。

## 典型用法

以下示例改写自 `src/test/core/` 下已有用例（`bus/bank/rect/type.range.*`），其余无测试覆盖的
小节单独标注。

```ts
import {
  createBus, NumRange, StrRange,
  Bank, Rects,
} from "@site0/tijs";

// —— 消息总线（改写自 bus.test.ts）——
let bus = createBus<number>();
bus.on("test", ({ name, data }) => console.log(name, data)); // 精确
bus.on("^(a|b)", (msg) => {});                               // 模式
bus.on("*", (msg) => {});                                    // 任意
bus.emit("test", 100);

// —— 汇率（改写自 bank.test.ts）——
Bank.exchange(10, {
  from: "USD", to: "CNY", table: { USD_CNY: 7.2 },
});                                  // 72
Bank.exchange(10, {
  from: "USD", to: "AUD", bridge: "CNY", precision: 2,
  table: { CNY_USD: 0.1389, CNY_AUD: 0.2128 },
});                                  // 15.32（桥接换算）
Bank.toBankText("1001.12345");       // "1,001.12"
Bank.parseCurrency("10USD");        // { cent: 1000, yuan: 10, currency: "USD" }
Bank.toYuanTokenText(105, "USD");    // "$1.05"

// —— 矩形（改写自 rect.test.ts）——
let rect = Rects.createBy({ left: 10, top: 20, width: 120, height: 120 });
rect.right === 130; rect.x === 70;  // 自动补全
rect.raw("wh");                      // { width: 120, height: 120 }
Rects.explainToArray("tlwh");        // ["height","left","top","width"]

// —— 范围类型（改写自 type.range.num/str.test.ts）——
let rg = new NumRange("(0,100]");
rg.contains(1);                      // true
rg.contains(0);                     // false（开区间）
rg.toRangeObj();                     // { $gt: 0, $lte: 100 }

let sg = new StrRange("(A,D]");
sg.contains("C");                   // true
sg.toRangeObj();                     // { $gt: "A", $lte: "D" }
```

`Icons`、`ti-random`、`ti-env`、`color`、`ti-com` 当前无单元测试覆盖，用法如下：

```ts
import { Icons, getRandomStr, getEnv, setEnv, TiColor, version } from "@site0/tijs";

Icons.getIcon("pdf");                // 内置映射到 far-file-pdf
Icons.fontIconHtml("zmdi-edit");     // '<i class="zmdi zmdi-edit"></i>'

getRandomStr(6);                     // 6 位随机串
getRandomObj(["a", "b", "c"]);      // 随机一项

getEnv("version") === version;      // 库版本
setEnv("dev", true);

let c = new TiColor("#FF8800");
c.hex;                               // "#FF8800"
c.light(20);                         // 变亮
```

## 注意事项

- **`_top` 是平铺导出**：`createBus/NumRange/TiColor/version/getEnv…` 直接从包顶层导入；
  只有 `Bank/Icons/Rects` 仍是命名空间对象，勿写成 `Top.Bank`。
- **`AnyRange` 字符串解析**：分隔符为 `, : ; ~`；`"(100)"` 与 `"(100,100)"` 等价（`$ne`）；
  不合法串直接抛错。**`contains` 对不匹配类型的值一律返回 `false`**（如 `NumRange.contains("abc")`）。
- **`Bank.parseCurrency` 默认 `unit=100`**：即传入数字视为"元"，`cent = input*100`；
  传 `"10EURA"` 这类非法串返回 `cent/yuan` 均为 `NaN`。
- **`Bank.exchange` 无桥接且找不到直接/反向汇率时抛错**（`Bridge currency cannot be empty` 或
  桥接失败），调用方需自行兜底。
- **`Rects.createBy(window)` 取的是视口 client 宽高**，不是 `innerWidth`；`toCss` 的 `right/bottom`
  是相对视口右/底边的距离。
- **`Rect.dockTo/dockIn/wrap/wrapCut` 在 rect.test.ts 中仅为空占位用例**，行为以源码实现为准。
- **`getEnv("ALL_BUS")` 是全局总线注册表 `Map`**，`TiBusImpl` 构造时自动登记、`depose()` 摘除。
- **`Icons.put` 里 `dft` 分支的写法**是 `_.assign(_DFT_FONT_ICON, dft)`——而 `_DFT_FONT_ICON`
  是字符串，`_.assign` 不会改动它，该入参当前版本实际不生效（保留备用）。

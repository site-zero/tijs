# `I18n` 国际化

## 职责

`I18n` 是 `src/core/text/ti-i18n.ts` 导出的无 UI 依赖国际化工具命名空间，只做一件事：维护一张
挂在 `globalThis.TI_I18N_SET` 上的全局消息表，并按 key 查表取文案。它提供语言包的并入、带
`i18n:` 前缀文案的解析、模板变量插值、语言键归一化等基础函数。

**分层机制（核心包 vs 组件局部包、`i18n:` 前缀约定、`installTiCoreI18n` /
`updateInstalledComponentsLangs` 启动引导、运行时切换语言）由概念篇讲透，本篇只列对外 API 与调用例子**，
不再展开，详见 [国际化 i18n](../10.concepts/04-i18n.md)。

## 导出清单

### 消息表存取

- **`all()`** —— 返回全局消息表 `MessageMap` 本身（`globalThis.TI_I18N_SET`），惰性创建。
- **`putAll(msgs)`** —— 用 `_.assign` 把一组 `key -> 文案` 并入全局表；同名键被覆盖，不清空旧消息。
- **`createEmptyI18nSet()`** —— 返回一个四种语言键都为空表的 `I18nSet` 骨架。

### 按 key 查表

- **`get(key, dft?)`** —— 直接按 key 查消息表；命中返回文案，未命中返回 `dft`，`dft` 也缺省时
  返回 key 本身。查表时 key 中的 `.` 会被替换为 `-`。
- **`getf(key, vars?)`** —— 按 key 取文案后用 `Str.renderTmpl` 做 `${var}` 变量替换；未命中返回 key。
- **`text(str, dft?)`** —— 解析 `i18n:` 前缀：带前缀则按其后的 key 走 `get`；不带前缀返回 `dft ?? str`。
- **`textOr(str?, dft?)`** —— 输入为 `null/undefined/空串` 时直接返回 `undefined`，否则走 `text`。
- **`textOrKey(str, dft?)`** —— 带 `i18n:` 前缀走 `get`；不带前缀时把整串也当作 key 再查一次表。
- **`textf(str, vars?)`** —— 带 `i18n:` 前缀走 `getf`；不带前缀则把整串当模板用 `Str.renderTmpl` 渲染。
- **`translate(str)`** —— 形如 `code:data` 的串，先 `get(code)` 再拼上 ` : data`；不含冒号则整体走 `get`。

### 语言键归一化

- **`toLangKey(lang)`** —— 把 `"zh-cn"`、`"zh_cn"` 这类输入归一化为内置 `I18nLang`
  （`en_us` / `en_uk` / `zh_cn` / `zh_hk`）。先按原值匹配，失败再 `_.snakeCase` 归一化；
  仍不识别则抛 `Invalid I18n language key`。

### 相关类型（来自 `_type`，随包导出）

- **`MessageMap`** —— `{ [k: string]: string }`，单种语言的 `key -> 文案` 表。
- **`I18nSet`** —— `{ en_us, en_uk, zh_cn, zh_hk }` 四种语言各自一张 `MessageMap`。
- **`I18nLang`** —— `keyof I18nSet`，即四种内置语言键之一。

## 典型用法

以下示例按源码行为改写（当前 `src/test/core/` 下没有独立的 i18n 单元测试，可对照 `ti-i18n.ts`
与概念篇例子核对）。

```ts
import { I18n } from "@site0/tijs";

// 1. 先往全局表里装消息（通常由 installTiCoreI18n / updateInstalledComponentsLangs 完成）
I18n.putAll({
  "ti-button-com-name": "按钮",
  "dt-past-in-min": "刚刚",
});

// 2. 按 key 查表
I18n.get("ti-button-com-name")        // "按钮"
I18n.get("no-such-key", "NA")         // "NA"
I18n.get("no-such-key")               // "no-such-key"（回退 key 本身）
I18n.get("ti.button.com-name")        // "按钮"（. 会被当作 - 查）

// 3. 解析 i18n: 前缀文案
I18n.text("i18n:ti-button-com-name")  // "按钮"
I18n.text("Hello")                    // "Hello"（无前缀原样返回）
I18n.text("i18n:missing", "缺省")     // "缺省"

// 4. textOr / textOrKey
I18n.textOr("")                       // undefined
I18n.textOrKey("ti-button-com-name")  // "按钮"（无前缀也当 key 查一次）

// 5. 带模板变量插值
I18n.putAll({ greet: "你好 ${name}" });
I18n.getf("greet", { name: "小白" })  // "你好 小白"
I18n.textf("i18n:greet", { name: "小白" }) // "你好 小白"

// 6. 语言键归一化
I18n.toLangKey("zh-cn")               // "zh_cn"
I18n.toLangKey("zh_HK")               // "zh_hk"
// I18n.toLangKey("fr")               // 抛错：Invalid I18n language key
```

## 注意事项

- **`I18n` 命名空间本身不保存“当前语言”状态**：消息表是所有语言消息并入的一张大表，切语言由
  `installTiCoreI18n` + `updateInstalledComponentsLangs` 重新装包完成（见概念篇）。本篇函数读取的
  是同一张全局表，不区分当前是哪种语言。
- **查表时 `.` 等价于 `-`**：`get("a.b")` 与 `get("a-b")` 命中同一键，两种写法互通。
- **`putAll` 是并入不是替换**：`_.assign` 浅合并，只覆盖同名键，其他语言消息保留。
- **`get` 一定返回字符串**：未命中时依次回退 `dft`、key 本身，不会返回 `undefined`；
  想要空值语义请用 `textOr`。
- **`translate` 的冒号是首个 `:`**：`get(code) + " : " + data`，且会对 `code`/`data` 各自去空白。
- **`toLangKey` 会抛错**：遇到不在四种内置键内的语言不要静默吞掉，调用方需自行捕获或提前校验。

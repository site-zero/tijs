# `Web` 浏览器 DOM 工具

## 职责

`src/core/web/` 是 TiJS 全部"跑在浏览器里"的无组件 UI 依赖工具集合，通过 `export * from "./web"`
平铺出口后，落在 `@site0/tijs` 顶层的是三个命名空间对象：

- **`CssUtils`** —— 类名合并、样式对象/字符串互转、尺寸单位换算、CSS 规则与样式表的解析/渲染。
- **`Dom`** —— 元素创建与增删改查、属性/数据/类名读写、祖先/兄弟节点遍历、元素定位停靠
  （`dockTo`）、主题与视口信息、滚动与剪贴板等杂项。
- **`EventUtils`** —— 键盘/指针事件修饰键状态抽取。

三者都不依赖 Vue 组件实例，可以在任何浏览器环境直接 `import { CssUtils, Dom } from "@site0/tijs"` 使用。
`web/index.ts` 同时把 `behaviors/` 再导出为 `Be`，那是一组"挂到元素上的一次性交互行为"，
单列一篇 [Be 行为扩展](150-be.md)。

> CSS 变量体系、主题变量（`--ti-color-*`、`--ti-measure-*`）与 SCSS mixin 的机制由
> [样式体系](../10.concepts/05-style-system.md) 讲透，本篇只列 JS 侧 `CssUtils`/`Dom` 的函数级清单，
> 不重复展开变量命名规则。

## 导出清单

### `CssUtils`：类名与样式合并

- **`mergeClassName(...args)`** —— 把字符串、数组、对象、函数形式的类名合并成
  `{类名: true}` 的对象；`mergeClassNameBy(context, ...args)` 额外给函数型类名传入 `context`。
- **`joinClassNames(...args)`** —— 同 `mergeClassName`，但输出空格拼接的字符串。
- **`mergeStyles(styles, { caseMode?, filter? })`** —— 合并一个或多个样式对象；键名默认按
  `kebab` 转换，以 `--` 开头的 CSS 变量名原样保留；`filter(key, val)` 可剔除/改名条目。
- **`pickGridItemStyle(sty)`** —— 从样式对象中挑出 `grid-*` 与 `justify-self/align-self` 条目。

### `CssUtils`：尺寸与单位换算

- **`toPixel(input, base = 100, dft = 0)`** —— 把 `45px`、`43%`、`2rem` 或数字转成像素；
  数字落在 `(-1, 1)` 视为百分比乘 `base`；解析失败返回 `dft`。
- **`toAbsPixel(input, { base = 100, dft = 0, remBase = 100, emBase = 14 })`** —— 纯字符串
  像素换算的底层实现（`px/rem/em/%`）。
- **`toSize(sz, { autoPercent?, remBase? })`** —— 反向：数值转 CSS 尺寸串；默认加 `px`，
  `remBase>0` 时输出 `rem`，`autoPercent` 且值在 `[-1, 1]` 时输出百分比。
  **`toSize2(sz)`** 固定 `autoPercent:false`；**`toSizeRem100(sz, options?)`** 固定 `remBase:100`。
- **`toStyle(obj?, options?)`** —— 把样式对象逐值走 `toSize`，键名转 kebab；
  `opacity/z-index/order` 不加单位；**`toStyleRem100`** 固定 `remBase:100`；
  **`toNumStyle(obj)`** 是 `toStyle` 的别名。
- **`scaleSize(scale = 1.0, W, H)`** —— 给定宽高之一与宽高比，补全另一边。

### `CssUtils`：背景与 CSS 规则序列化

- **`toBackgroundUrl(src?, base = "")`** —— 拼出 `url("...")`；`base` 存在时先拼路径。
- **`toBackgroundUrlBy(src, tmpl?)`** —— `src` 为对象时先用 `tmpl` 渲染模板再包 `url()`。
- **`parseCssRule(rulesStr, flt?)`** —— 解析 `"color:red; padding:2px"` 形式的规则串为对象，
  属性名转驼峰；状态机正确处理引号内分号；`flt` 是 `Dom.attrFilter` 兼容的过滤器。
- **`toCssStyle(input?)`** —— 字符串走 `parseCssRule`，对象走 `toStyle`，`nil` 返回 `{}`。
- **`parseAndTidyCssRule(rule, { filter?, parseBackground?, nameCase?, urlRewrite? })`** ——
  解析并整理单条规则：拆解 `background` 简写为 `background-*`，`background-position` 拆成
  `-x/-y`（`0→left/top`、`50%→center`、`100%→right/bottom`），可经 `urlRewrite` 重写背景图地址。
- **`parseBackground(str, { nameCase = "kebab" })`** —— 独立解析 `background` 简写串。
- **`renderCssRule(css = {})`** —— 样式对象序列化为 `"key:value;..."` 串；数字自动加 `px`
  （`opacity/z-index/order` 除外），`null/undefined/空白串` 条目被丢弃，`--` 变量原样输出。
- **`renderCssStyleSheet(sheet = [], scope?)`** —— 把 `[{ selectors, rules }]` 数组渲染为完整 CSS 文本。
- **`parseCssStyleSheet(input)`** —— 反向：CSS 文本解析回 `CssSheet[]`。

### `Dom`：元素创建与 DOM 增删

- **`createElement(options, $doc = document)`** —— 按 `EleOptions` 建元素：`tagName` 默认 `div`，
  支持 `attrs/props/data/className/style`，并可经 `$p/$refer` 直接插入 DOM 树。
- **`appendToHead / appendToBody / appendTo / prependTo`** —— 四种挂载位置。
- **`wrap($el, $newEl)`** —— 用新元素包住旧元素；**`unwrap($el)`** —— 拆掉包裹层并把孩子上移。
- **`replace($el, $newEl, keepInnerHTML = false)`** —— 替换节点；**`renameElement($el, newTagName, attrFilter?)`** ——
  换标签名并复制属性。
- **`remove(selectorOrElement, context?)`** —— 按选择器或元素删除。

### `Dom`：属性、数据、类名、样式读写

- **`attr($el, name, dft?)` / `attrs($el, flt = true)`** —— 读属性；`"true"/"false"` 字符串自动转布尔。
- **`setAttrs($el, attrs = {}, prefix?)`** —— 批量写属性；`null` 删除、`undefined` 跳过，
  对象/数组值 `JSON.stringify`，`style` 值走 `CssUtils.renderCssRule`。
- **`removeAttrs($el, flt = false)`** —— 按过滤器删除属性，返回被删内容。
- **`getData($el, flt = true)` / `setData($el, data = {})`** —— `data-*` 数据集读写，键名自动 kebab/camel 转换。
- **`getClassList(className, { filter?, dftList? })`** —— 类名串/数组/元素解析为去重数组。
- **`setClass / addClass / removeClass / hasClass / hasOneClass`** —— 类名增删判。
- **`getStyle($el, flt = true)`** —— 读行内样式表对象；**`getComputedStyle($el, name?)`** —— 读计算样式；
  **`getOwnStyle($el, filter?)`** —— 解析元素 `style` 属性字符串。
- **`setStyle($el, css = {})`** —— 整体覆盖行内样式；**`updateStyle($el, css = {})`** —— 逐条增量更新，
  空串删除属性，数字加 `px`（`opacity/z-index` 除外）。
- **`setStyleValue($el, name, val, oldVal)`** —— 单值设置，新旧相同则跳过。
- **`formatStyle(css, caseMode)`** —— 把样式对象键名统一大小写并给数字加 `px`。
- **`textToHtml(str)`** —— 转义 `& < >` 并把换行换成 `<br>`（来自 `web-dom-html.ts`）。

### `Dom`：节点查找与遍历

- **`find(selector, qc?)` / `findAll(selector = "*", qc?)`** —— 封装 `querySelector(All)`；
  `selector` 为空时 `find` 返回 `qc` 本身或 `document.body`。
- **`is($el, selector)`** —— 等同 `matches`，也可与另一个元素比较身份。
- **`closest($el, filter, { includeSelf? })` / `closestByTagName($el, tagName, opts?)`** —— 向上找祖先。
- **`prev / prevByTagName / prevUtil` 与 `next / nextByTagName / nextUtil`** —— 沿兄弟轴向前/后找。
- **`seek($el, flt, by)` / `seekUntil($el, flt, setup)` / `seekByTagName`** —— 通用遍历引擎；
  `by` 给出下一步走哪（父/前兄/后兄……），`flt` 是 `elementFilter` 兼容的匹配条件。
- **`parentsUntil($el, selector, setup?)`** —— 沿父轴收集直到命中。
- **`elementFilter(test?)` / `attrFilter(filter)`** —— 把选择器串、正则、布尔、函数、数组
  归一化为统一谓词。
- **`inScope(src, scope?)`** —— `src` 是否在 `scope` 子树内（跨文档返回 `false`）。
- **`eventCurrentTarget(evt, selector?, scope?)`** —— 从事件目标向上委托命中元素。
- **`getHeadingLevel($h?)` / `getMyHeadingLevel($el)`** —— 取 `H1-H6` 层级。
- **`isEmpty($el)`** —— 递归判断元素是否无任何可见内容（`IMG/VIDEO/AUDIO` 直接算非空）。

### `Dom`：定位停靠与视口

- **`Rects` 见 [_top 顶级工具](160-top.md) 的矩形小节**；`Dom` 侧在此之上提供：
- **`applyRect($el, rect, keys = "tlwh", viewport?)`** —— 把 `Rect` 转成 CSS 并 `updateStyle` 到元素上。
- **`dockTo($src, $ta, options)`** —— 把浮层 `$src` 停靠到目标 `$ta` 旁：`mode` 为 `"H"/"V"`，
  `axis.x/y` 可为 `auto` 自动选边，`space` 控制间距，`coord` 为 `"win"/"target"`，
  `position` 强制 `fixed/absolute`；视口边缘自动回绕。
- **`scrollIntoView($view, $row, { to?, axis?, smooth? })`** —— 让滚动容器把 `$row` 滚入可视区。
- **`pendingMoreWhenScrolling({ $view, $more })`** —— 返回 `$more` 已暴露在视口的比例 `0-1`，
  供滚动加载判断。
- **`scrollBarSize()`** —— 首次调用时构造探测节点测量滚动条宽高并缓存。
- **`isTouchDevice()`** —— 按 UA 判断触屏设备（含 iPadOS 的 `maxTouchPoints` 特例）。
- **`getRemBase($doc = document)`** —— 读根元素 `fontSize` 换算 rem 基准像素值。

### `Dom`：主题、文档与杂项

- **`getWindowTheme()`** —— 读 `prefers-color-scheme`；**`getDocumentTheme(doc?)`** —— 先看
  `<html>` 类名上的 `light/dark`，否则跟随系统。
- **`RootThemeClass`** —— Vue `ref<WindowTheme>`，`watchDocumentTheme()` 在模块加载时自动启动，
  观察 `<html>` class 变化并同步该 ref。
- **`watchDocument / unwatchDocument(event, handler)`** —— `document` 上的监听封装。
- **`setDocumentTitle(title)`** —— 同时更新 `og:title` meta。
- **`setDocumentIcon(icon, type = "image/x-icon")`** —— 换 favicon；`type: "emoji"` 时用 canvas
  把 emoji 画成图标。
- **`moveCursorTo(input, pos?)`** —— 输入框聚焦并把光标移到指定位置（默认末尾）。
- **`getFromClipBoard(clipboardData, filter)` / `getImageDataFromClipBoard(clipboardData)`** ——
  从粘贴事件数据里挑条目/挑图片文件。
- **`loadImageRawData(url, { asBase64?, dataUrlPrefix? }, $doc?)`** —— 把图片画到 canvas 上取
  base64 DataURL 或 `ImageData`。
- **`autoRootFontSize({...})` / `watchAutoRootFontSize(...)`** —— 按视口宽度与设计稿宽度换算
  根字号并触发回调（`phoneMaxWidth/tabletMaxWidth/designWidth/max/min`）。
- **`ownerWindow($el)`** —— 从元素/文档/Window 取回 `Window`。

### `EventUtils`

- **`getKeyboardStatus(e)`** —— 从 `KeyboardEvent` 或 `PointerEvent` 抽取
  `{ altKey, ctrlKey, shiftKey, metaKey }`；其他事件类型返回 `{}`。

## 典型用法

`web` 命名空间当前无单元测试覆盖，以下示例按源码行为核对编写。

```ts
import { CssUtils, Dom, EventUtils } from "@site0/tijs";

// —— CssUtils：合并类名与样式 ——
CssUtils.mergeClassName("btn primary", { disabled: true }, "large")
// { btn: true, primary: true, disabled: true, large: true }
CssUtils.joinClassNames("a b", ["c", "d"])      // "a b c d"

// 数值自动加 px；opacity 不加
CssUtils.toStyle({ width: 100, opacity: 0.5 })
// { width: "100px", opacity: 0.5 }

// CSS 串 ↔ 对象
CssUtils.parseCssRule("color:red; padding:2px")
// { color: "red", padding: "2px" }
CssUtils.renderCssRule({ color: "red", width: 100 })
// "color:red;width:100px"

// —— Dom：创建并挂节点 ——
let $el = Dom.createElement({
  tagName: "div",
  className: "my-box",
  style: { width: 100, height: 40 },
  attrs: { "data-role": "tip" },
});
Dom.appendToBody($el);

// 读写 data-*
Dom.getData($el)                 // { role: "tip" }
Dom.setData($el, { role: "ok" })

// 沿兄弟轴查找
let $row = Dom.next($el, "TR");  // 下一个 TR 元素

// 浮层停靠：把下拉面板贴到触发按钮下方
Dom.dockTo($panel, $button, { mode: "H" });

// —— EventUtils ——
input.addEventListener("keydown", (e) => {
  let k = EventUtils.getKeyboardStatus(e);
  // { altKey, ctrlKey, shiftKey, metaKey }
});
```

## 注意事项

- **`Dom.parseCssRule` / `Dom.renderCssRule` 是已弃用包装**：调用时会 `console.warn`，
  请改用 `CssUtils.parseCssRule` / `CssUtils.renderCssRule`。
- **`toSize(0)` 原样返回数字 `0`** 而不是 `"0px"`；`toStyle` 对 `opacity/z-index/order`
  一律不加单位。
- **`renderCssRule` 丢弃空值条目**：`null/undefined/空白串` 不会输出，可用来"删除"属性。
- **`dockTo` 通过 `_.delay(..., 0)` 异步写样式**：调用后立刻读 `$src.style` 可能还没生效。
- **`watchDocumentTheme()` 在模块加载时自动执行一次**；Node 环境无 `MutationObserver` 时静默跳过。
- **`getImageDataFromClipBoard` 等剪贴板 API 依赖 `navigator.clipboard`**，非安全上下文下不可用。
- **`is($el, selector)` 在浏览器不支持 `matches` 时直接抛错**，仓库内已无降级实现。

# `Be` 元素行为扩展

## 职责

`Be` 是 `src/core/web/behaviors/` 导出的一组**一次性交互行为**：每个函数接收一个宿主元素
（或选择器），在页面上临时叠加一层 DOM 完成某个动作——闪烁提示、行内改名、复制剪贴板、
以表单方式打开链接、弹出文件选择框——用完即拆。它不是组件，也不挂生命周期，业务代码
`import { Be } from "@site0/tijs"` 后按需调用即可。

出口形态：`ti-exports.ts` 为 `export * as Be from "./web/behaviors"`，`behaviors/index.ts`
把四个文件平铺进 `Be`，唯独 `be-clipboard.ts` 单独收进 `Be.Clipboard` 子命名空间：

- **`Be.BlinkIt`** —— 闪烁高亮提示。
- **`Be.EditIt`** —— 在元素上覆盖输入框就地改文字。
- **`Be.OpenUrl`** —— 用隐藏表单提交方式打开链接。
- **`Be.chooseFiles`** —— 弹出系统文件选择框。
- **`Be.Clipboard`** —— 写剪贴板 / 读剪贴板图片。

## 导出清单

### 闪烁提示 `BlinkIt`

- **`BlinkIt(it, options?)`** —— 在目标元素位置盖一块黄色半透明遮罩，渐隐后自动移除。
  - **触发条件**：手动调用；`it` 为选择器或元素，找不到时静默返回。
  - **挂载方式**：`Dom.createElement` 建 `div.ti-blink-light`，按目标 `Rect` 定位后
    `appendToBody`，`speed` 毫秒后淡出并移除。
  - **对外回调**：`options.update(blinkEl)` 可在挂载前改造遮罩样式；
    `options.after(targetEl)` 在移除后回调宿主元素。
  - **`speed`** 默认 `800` 毫秒。

### 剪贴板 `Be.Clipboard`

- **`Clipboard.write(input)`** —— 写文本到剪贴板；非字符串先走 `Str.anyToStr`。
  优先 `navigator.clipboard.writeText`，不可用时退化为隐藏 `textarea` + `execCommand("copy")`。
- **`Clipboard.readImageFile(fileName?)`** —— `async`，从剪贴板读第一张 `image/*` 内容并包成
  `File`；无图片或 API 不可用时返回 `undefined`。文件名缺省为 `screenshot-yyyyMMddHHmmss.png`。

### 行内编辑 `EditIt`

- **`EditIt(it, options?)`** —— `async`，返回 `Promise<string | undefined>`。
  在宿主元素上覆盖一个 `<input>`/`<textarea>`，字体、边框、对齐等计算样式从宿主继承，
  确认后返回新文本；**取消、报错或文字未改动时返回 `undefined`**。
  - **触发条件**：手动调用；找不到目标元素时 `console.warn` 并返回 `undefined`。
  - **挂载方式**：`position: fixed` 覆盖在宿主原位置，宿主暂时 `visibility: hidden`；
    结束后恢复并拆除输入框。
  - **确认/取消**：单行模式回车确认、`Esc` 取消；多行模式 `enterAsConfirm=true` 时回车确认、
    `Ctrl+回车` 换行；失焦视为确认。**页面滚动、窗口 resize、宿主矩形位移超过 0.5px 一律取消**。
  - **`EditItOptions`**：`multi`（默认 `false`）、`enterAsConfirm`（默认 `false`）、
    `newLineAsBr`（输出把换行写成 `<br>`，默认 `false`）、`text`（初始文字，缺省取宿主 `innerText`）、
    `trim`（默认 `true`）、`width/height`（≤0 时取宿主尺寸）、`extendWidth`（单行默认 `true`）、
    `extendHeight`（多行默认 `true`）、`selectOnFocus`（默认 `true`，仅单行生效）。

### 打开链接 `OpenUrl`

- **`OpenUrl(url, options?)`** —— 构造一个隐藏 `<form>`，把参数塞成 hidden input，
  `delay`（默认 `100` 毫秒）后 `submit()` 并移除表单。
  - **`OpenUrlOptions`**：`target` 默认 `"_blank"`、`method` 默认 `"GET"`、`params` 对象、`delay`。
  - URL 上自带的 query string 会被解析并入 `params`；`url` 为空直接返回。
  - 用于需要带 **POST** 参数打开新页面的场景（`window.open` 无法 POST）。

### 选择文件 `chooseFiles`

- **`chooseFiles(options?)`** —— `async`，返回 `Promise<File[]>`。创建隐藏的
  `<input type="file">` 并 `.click()` 弹出系统选择框。
  - **`ChooseFilesOptions`**：`multi` 默认 `false`、`accept` 透传 `accept` 属性。
  - 用户取消选择时 `resolve([])`（不 reject）；异常才走 `reject`。

## 典型用法

`Be` 命名空间当前无单元测试覆盖，以下示例按源码行为核对编写。

```ts
import { Be } from "@site0/tijs";

// 操作成功后在按钮上闪一下黄
Be.BlinkIt(".ti-button-ok", {
  speed: 800,                       // 渐隐时长
  after: ($el) => console.log("blink done", $el),
});

// 复制任意文本到剪贴板
Be.Clipboard.write("hello tijs");
// 把剪贴板里的截图读成 File，直接喂给上传接口
let file = await Be.Clipboard.readImageFile("my-shot");

// 双击表格单元格就地改名
let $cell = document.querySelector("td.name");
let newText = await Be.EditIt($cell, { trim: true });
if (newText !== undefined) {
  // 确认且文字有变化，提交保存
}

// 以 POST 方式打开报表下载页
Be.OpenUrl("/report/export", {
  method: "POST",
  target: "_blank",
  params: { id: "1001", fmt: "pdf" },
});

// 弹出文件选择框
let files = await Be.chooseFiles({ accept: "image/*", multi: true });
files.forEach((f) => console.log(f.name, f.size));
```

## 注意事项

- **`EditIt` 的取消很敏感**：滚动、缩放、宿主位移都会取消编辑并返回 `undefined`；
  只有"确认且文本与原值不同"才会 resolve 出新文本。
- **`EditIt` 依赖 `navigator`/`document`**：在非浏览器环境直接返回 `undefined`。
- **`Be.Clipboard.readImageFile` 需要权限**：`navigator.clipboard.read()` 仅在安全上下文且
  用户授权后可用；不满足时静默返回 `undefined`。
- **`OpenUrl` 是延迟提交**：`delay` 默认 100ms 内表单还挂在 body 上，期间不要重复调用。
- **`chooseFiles` 不 reject 取消**：用户在系统弹窗点取消时 resolve 空数组，不要写成抛错分支。
- behaviors 内部使用 `@site0/tijs` 别名导入 `Dom/DateTime/Str/Rects`，与组件库同一套工具。

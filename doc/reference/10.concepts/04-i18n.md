# 国际化 i18n

## 要解决的问题

组件库里同时存在两类文案：

- **核心通用文案**：按钮"添加"、提示"请输入"、匹配条件运算符等，全库共用一份。
- **组件局部文案**：每个组件自己的名称、示例名、专有提示，散落在各个组件目录里。

需要一套轻量方案：任意位置只要写一个带前缀的 key，就能在当前语言下取到文案；启动时先装
核心语言包，再把各组件局部语言包按组件名加前缀并入；运行时还能切换语言。TiJS 没有引入
第三方 i18n 插件，而是用 `core/I18n` 命名空间加一个全局消息表实现。

## 解决思路

### 全局消息表

全局唯一的 `MessageMap` 挂在 `globalThis.TI_I18N_SET` 上，惰性创建。所有语言的消息都
合并进这一张表，读取时按键查找。`I18n.all()` 返回整张表，`I18n.putAll(msgs)` 批量并入。

### `i18n:` 前缀约定

文案字符串以 `i18n:` 开头时，后面部分被当作消息 key 去查表；不带前缀则原样返回：

```ts
I18n.text("i18n:ti-button-com-name")   // 查表得到当前语言下的"按钮"
I18n.text("Hello")                     // 原样返回 "Hello"
```

- **`I18n.text(str, dft?)`** —— 解析 `i18n:` 前缀；找不到时返回 `dft`，再回退原串。
- **`I18n.textOr(str?, dft?)`** —— 输入为空直接返回 `undefined`。
- **`I18n.textOrKey(str, dft?)`** —— 不带 `i18n:` 前缀时，也把整串当作 key 查一次表。
- **`I18n.get(key, dft?)`** —— 直接按 key 查表，命中失败返回 `dft`，再回退 key 本身。
- **`I18n.getf(key, vars)` / `I18n.textf(str, vars)`** —— 取到文案后用 `Str.renderTmpl`
  做模板变量替换。
- **`I18n.translate(str)`** —— 形如 `code:data` 的字符串，先翻译 `code` 再拼接 `data`。

### 语言键归一化：`toLangKey`

内置四种语言键：`en_us`、`en_uk`、`zh_cn`、`zh_hk`。`toLangKey(lang)` 先按原值匹配，
失败再用 `_.snakeCase` 归一化，因此 `"zh-cn"`、`"zh_cn"` 都能解析为 `zh_cn`；
仍不识别则抛 `Invalid I18n language key`。

### 启动引导：核心包 + 组件包

业务应用按顺序调用两个引导函数（见根 `README.md` 的 `main.ts` 引导步骤）：

```ts
// 1. 装入指定语言的核心语言包
installTiCoreI18n("zh-cn");

// 2. 把各组件局部语言包并入全局表（通常紧随 installTiComponents）
updateInstalledComponentsLangs("zh-cn");
```

**`installTiCoreI18n(lang, updateComponents?)`**：

- 核心包映射：`zh_cn` 与 `zh_hk` 共用 `src/i18n/zh-cn.ts`，`en_us` 与 `en_uk` 共用
  `src/i18n/en-us.ts`。
- 归一化语言键后把对应消息 `putAll` 进全局表。
- 第二个参数为 `true` 时，紧接着执行 `updateInstalledComponentsLangs(langKey)`。

**`updateInstalledComponentsLangs(lang)`**：遍历全局注册表中每个组件：

1. 取该组件 `i18n[langKey]` 局部消息表。
2. 给每个 key 补前缀 `<kebab-case 组件名>-`；若 key 已经带该前缀则不重复添加。
3. `putAll` 并入全局表。

例如 `TiButton` 局部包里的 `com-name`，并入后全局键为 `ti-button-com-name`；
`ti-button-index.ts` 里 `text: 'i18n:ti-button-com-name'` 才能解析到。

### 组件局部语言包写法

组件 `ti-xxx-index.ts` 内定义四个语言分组（未覆盖的语言指向同一份即可）：

```ts
const zh_cn = { "com-name": "按钮", /* ... */ };
const en_us = { "com-name": "button", /* ... */ };

const TiComInfo: TiComInfo = {
  // ...
  text: "i18n:ti-button-com-name",
  i18n: { en_us, en_uk: en_us, zh_cn, zh_hk: zh_cn },
};
```

示例名 `exampleProps[].text`、组件内 `text`/`placeholder` 等文本字段都可以写
`i18n:` 前缀；带 `autoI18n` 开关的组件，缺省开启时会自动调用 `I18n.text` 解析。

## 关键细节

- **key 的分隔符**：查表时 key 中的 `.` 会被替换成 `-`，两种写法可以互通。
- **语言包是并入不是替换**：`putAll` 覆盖同名键，不会清空其他语言消息；运行时切换语言
  需要重新调用 `installTiCoreI18n` 与 `updateInstalledComponentsLangs`。
- **组件局部包必须走注册表安装**：单独在业务里 `tiPutComponents` 注册的自定义组件，
  其局部语言包同样要等 `updateInstalledComponentsLangs` 执行后才生效。
- **`autoI18n = false`** 时组件跳过 `I18n.text`，把 `text` 原样显示，适合传完整现成文案。

## 主要代码入口

- `src/core/text/ti-i18n.ts` —— `I18n` 命名空间全部函数与全局消息表。
- `src/core/ti-coms.ts` —— `installTiCoreI18n`、`updateInstalledComponentsLangs`。
- `src/i18n/zh-cn.ts`、`src/i18n/en-us.ts` —— 核心语言包（含 `match/` 子包合并）。
- 各组件 `ti-xxx-index.ts` —— 局部语言包范本。

# note/ — 工作过程笔记

> 通读源码、排查问题过程中的**阶段性认识、踩坑记录、待办线索**。
> 本目录是私有工作区：**不发布到文档站，内容可能过时，不作为事实引用**。

## 收录约定

- 什么放这里：尚未核实的猜想、排查中间结论、跨篇目的综合理解草稿。
- 什么不放这里：已核实的事实——那应该写进 `doc/reference/` 对应篇目。
- 笔记被核实并搬进 `doc/reference/` 后，**删除或一行注明去向**，避免两处漂移。
- 文件 kebab-case，开头注明日期与背景（在做什么任务时记的）。
- 文档站构建配置（`doc/www-gen-site.json5`）不包含本目录，不要往里加发布配置。

## 与各目录的边界

| 内容 | 去处 |
| --- | --- |
| 已核实的机制 / 用法 | `doc/reference/` |
| 可复用的执行套路（面向 Agent） | `doc/skill/` |
| 未核实的中间认识（本目录） | `doc/note/` |
